# Python-programs
This repository has open-sourced 5 Python programs.
# Python 小程序合集
## 一、项目说明
本合集包含5个独立实用的Python小程序，基于Python语言编写，实现各类趣味小功能与实用小工具。
## 二、文件结构说明
总文件夹内包含5个项目子文件夹，每个文件夹对应一款完整独立的小程序；
每个子文件夹内统一包含3类文件：
1. *.py 文件：可直接运行的完整源代码
2. 运行结果文件夹：存放程序运行截图、输出效果展示
3. *.pdf 文件：代码排版文档，用于快速查阅、对照学习
## 三、运行说明
本地安装好Python运行环境后，直接双击运行对应文件夹内的 .py 源码即可。
无需额外复杂依赖与手动配置，简单开箱即用。
